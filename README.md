# CRM Manager - React, Laravel, MySQL, Docker
Just a basic CRM boilerplate to start directly coding on React, Laravel and MySQL with Docker Compose.

## Frontend
- NodeJS lts
- React 19.0.0
- Vite

## Backend
- PHP 8.4 
- Laravel 12


## MySQL and PhpMyAdmin

MySQL Version: 5.7.x

## Using the Project

Run the setup script 

```
./setup.sh
```
